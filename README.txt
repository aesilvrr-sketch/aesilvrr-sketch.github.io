SHIFTpay UK — phone-first pay planner

WHAT IS INCLUDED
- Primark break preset based on the shift/break pattern confirmed in the conversation.
- Holiday shifts: all scheduled hours paid, including normal break time.
- 4-week pay periods.
- Gross pay, estimated take-home, Income Tax and employee National Insurance.
- "How much can I still work?" deduction-free headroom.
- Extra-shift scenario planner.
- Night/premium hours.
- Actual payslip history.
- CSV export + JSON backup/restore.
- Data stored locally on-device only.

DEFAULT PERSONAL SETTINGS INCLUDED
- £13/hour.
- 20% night premium.
- Tax code number 1253.
- Week 1 / non-cumulative tax estimate.
- NI category M.
- Current period seeded as 19 Jul–15 Aug 2026 with the shifts supplied in chat.

IMPORTANT
Tax and NI are estimates. HMRC/Primark payroll can differ due to tax-code basis, exact payroll tables/rounding, cumulative corrections, benefits, other jobs and other deductions.

INSTALL ON IPHONE / ANDROID AS A HOME-SCREEN APP
This is a PWA (Progressive Web App). PWAs need to be opened from an HTTPS website for full installation/offline behaviour.

1. Upload the contents of this folder to any HTTPS static host (for example GitHub Pages, Netlify, Cloudflare Pages, or your own site).
2. Open the resulting site in Safari (iPhone) or Chrome (Android).
3. iPhone: Share -> Add to Home Screen -> Add.
   Android: browser menu -> Install app / Add to Home screen.

You can also open index.html directly on a computer to use the calculator immediately; service-worker installation is skipped when opened as a local file.
